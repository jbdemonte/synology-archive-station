# Archive Station 1.1.0-8

This release adds optional Internet Archive accounts for authorized restricted downloads, records the integrity check performed on each completed file, and fixes navigation, localization and task-state defects found since 1.0.2.

## Internet Archive accounts

- Connect an optional Internet Archive account in **Settings** with your email and password. Public downloads keep working without an account; Archive Station itself still relies on your DSM administrator session.
- Analysis includes restricted files when a session is available. Internet Archive checks the account's permission when each file downloads; signing in does not unlock content the account is not authorized to access.
- Refresh an existing task's file list after connecting to add previously excluded restricted files without discarding completed downloads.
- Credentials are remembered by default so expired sessions renew automatically. Passwords are encrypted with Fernet and a private local key. Uncheck the option for session-only storage, or forget the saved password without disconnecting. S3 keys are never saved.
- Concurrent downloads share one bounded renewal and wait for the login cooldown without consuming retry attempts. Invalid credentials stop automatic login until corrected.
- If a saved session cannot be renewed, public files remain downloadable anonymously, including after a restart. Account errors appear only when a resource actually refuses access.
- Resume and checksum verification work for authenticated transfers. External or insecure redirects and login pages returned in place of a file are refused.

## Integrity reports

- Download reports show the check actually performed on each completed file: matching SHA-1 or MD5, size only, no reference available, or not recorded by an older version. Results persist across restarts and setting changes, and include resumed files and reused existing files.
- Reports record where each size came from (archive metadata, HTTP response or observed download) and the date of the last check. **Verify and complete** cannot turn a locally observed length into a successful reference-size check.
- Files completed by earlier versions are marked **Check not recorded**. Upgrading does not reread them; use **Verify and complete** for a fresh check.
- The source-file mode now reads **All accessible files** instead of **All public files**.

## Navigation and keyboard

- The **Choose files** list scrolls inside small DSM windows with a visible scrollbar and a fixed **Done** button. Changing page or folder returns to the first row; checking a file keeps the scroll position.
- Changing page in a task's file list brings the first row of the new page into view.
- Task rows, checkboxes and expand buttons keep keyboard focus through automatic refreshes and after pressing Enter.
- **Resume** now applies only to paused or cancelled tasks. Tasks with failed files use **Retry**, which keeps partial files.

## Messages, tasks and packaging

- Polish is detected from the DSM language. Schedule, file path, filter, file/folder conflict and Archive.org unavailability messages are translated into all 27 languages. Dropped connections are reported as Archive.org being unavailable instead of an internal error.
- Cancelling a task releases its disk space reservation; tasks cancelled by earlier versions are repaired at startup.
- Items with several titles show readable text. Reports no longer recreate the folder of a completed archive that was moved or removed.
- The add button shows the remaining task count after a partial failure.
- Standard Python installations now declare the cryptography dependency. The DSM package still bundles its dependencies for offline installation.

## Install or upgrade

Download **ArchiveStation-1.1.0-8-x86_64.spk** below and select it in **DSM Package Center → Manual Install**. Install over the existing package; do not uninstall first. Close and reopen Archive Station afterward to load the updated interface.

The release targets **DSM 7 on x86_64**. Tasks, settings, partial downloads and downloaded files are preserved; running tasks resume after the service restarts.

## Validation and known limitation

- Automated checks cover the backend, formatting and browser scenarios. Account features are tested with simulated Internet Archive responses; no real credentials are included in tests, screenshots or release artifacts.
- On a **DS918+ running DSM 7.1.1**, this build was installed over 1.1.0-7 while a 24-file, 46.9 GiB task was paused mid-download. Task records, settings, completed files and partial files were preserved, and the task resumed. All 24 files completed with SHA-1 verification. Six files that had stopped after repeated network timeouts and were resumed from partial data were rehashed independently; their SHA-1 and MD5 matched Archive.org's published checksums.
- Restricted downloads with a real Internet Archive account, other DSM versions and other models have not been hardware-tested for this release.
- Network timeouts count against **Retries after an error** with a short backoff. During a long outage, files can reach that limit and the task stops with failed files; select **Retry** to continue from the partial data.
