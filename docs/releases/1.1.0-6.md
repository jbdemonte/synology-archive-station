# Archive Station 1.1.0-6

## Public downloads and account recovery

- Public files remain downloadable anonymously when a saved Internet Archive session cannot be renewed, including after a restart. Account errors are surfaced when a resource actually refuses access.
- Archived HTML files are accepted regardless of their filename extension. Authentication pages are identified by their destination URL.
- Downloads wait for the shared login cooldown without consuming file retry attempts. Transient network failures, truncated login responses, local key errors and clock skew remain recoverable; only authentication refusals persist a blocked-login state.
- A fresh successful login can replace a corrupt local encryption key. Cached failures no longer retain exception tracebacks, and successful requests clear stale transient warnings while preserving retry limits.
- A request already in flight can retry with a newly connected account. Routine session renewal preserves file selections; changing accounts invalidates them even if analysis and login finish concurrently.
- Restricted-file notices respect filename and original-file filters. Manual login cooldowns no longer claim that a completed attempt is still running.

## Integrity reports and packaging

- Files retain whether their size came from archive metadata, an HTTP response or an observed download. **Verify and complete** cannot turn a locally observed length into a successful reference-size check.
- Older size-only results without recorded size provenance are conservatively marked **Check not recorded**. Hash results, completed files, partial downloads and task state are preserved.
- Reports show the last recorded check date. Integrity aggregates are computed for reports instead of every progress poll.
- Standard Python installation now declares its cryptography dependency. The standalone DSM package still includes its dependencies for offline installation.

Upgrading does not automatically recheck completed downloads. Account settings and partial files are retained; running tasks resume after the service restarts.
