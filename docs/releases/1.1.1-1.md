# Archive Station 1.1.1-1

This release stops saving Internet Archive passwords. Archive Station now keeps only the account session, which Internet Archive typically issues for about a year, and asks you to reconnect when it expires.

## Internet Archive account

- The password is sent to Internet Archive for a manual login and is never stored. **Remember credentials**, **Forget password** and automatic session renewal are removed.
- Only the account email, session cookies and expiration are kept, in `archive-account.json` with owner-only permissions. Protect this file and its backups as account credentials.
- When the session expires, Settings shows **Session expired. Reconnect the account.** Public files keep downloading anonymously; restricted files report an access error until you log in again.
- The package no longer bundles `cryptography`, `cffi` or `pycparser`, and is about 5 MiB smaller.

## Upgrading from 1.1.0

Install over the existing package through **Package Center → Manual Install**; do not uninstall first. At startup, a saved encrypted password and its `archive-account.key` are deleted, and the current session is kept. Older backups are not changed. Close and reopen Archive Station to load the updated interface.

Downgrading to 1.1.0 discards the saved session: log in again after a downgrade.

Tasks, settings, partial downloads and downloaded files are preserved; running tasks resume after the service restarts.
