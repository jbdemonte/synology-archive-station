# Archive Station 1.1.0-5

Download reports now show the integrity checks actually performed on completed files: matching SHA-1 or MD5, size-only checks, no reference check, and checks not recorded by older versions. Results persist across package restarts and changes to the verification setting. Resumed files and existing files reused after verification are included.

Earlier completed files remain marked **Check not recorded**. Upgrading preserves their download state and does not reread them automatically; use **Verify and complete** for a fresh check and recorded result. Counts describe the file at completion, not a continuous integrity scan.

The source-file mode now reads **All accessible files** instead of **All public files**, consistent with authorized Internet Archive account access. This mode selects file types; it does not describe access permissions.

This revision also includes the account and file-picker improvements from 1.1.0-3. Task state, partial downloads and saved account settings are preserved during upgrades.
