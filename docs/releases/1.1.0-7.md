# Archive Station 1.1.0-7

## Navigation and keyboard use

- Changing pages or folders in **Choose files** returns the list to its first row. Checking a file keeps the current scroll position.
- Changing pages in a task's file list brings the first row of the new page into view.
- Task rows, row checkboxes and expand buttons keep keyboard focus through automatic refreshes and after pressing Enter.
- The add button shows the remaining task count after a partial failure.

## Messages and languages

- Polish is detected from the DSM language setting.
- Schedule, file path, filter and file/folder conflict errors are translated in all 27 languages, as is the message shown when Archive.org is unavailable.
- Dropped connections to Internet Archive are reported as Archive.org being unavailable instead of an internal error.

## Tasks and reports

- Cancelling a task clears its disk space hold. Tasks cancelled by earlier versions are repaired at startup.
- Items with several titles show readable text instead of a Python list.
- Reports no longer recreate the folder of a completed archive that was moved or removed.

Upgrading does not automatically recheck completed downloads. Account settings and partial files are retained; running tasks resume after the service restarts.
