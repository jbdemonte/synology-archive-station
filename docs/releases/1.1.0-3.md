# Archive Station 1.1.0

## Internet Archive accounts

- Connect an optional Internet Archive account in Settings using your email and password. Public downloads continue to work without an account; the application itself still uses your DSM administrator session.
- Include restricted files in analysis when a session is available. Internet Archive checks the account's permission when each file downloads. Signing in does not unlock content the account is not authorized to access.
- Refresh an existing task's file list after connecting to add previously excluded restricted files without discarding completed downloads.
- Remember credentials by default to reconnect automatically when a session expires. Passwords are encrypted with Fernet and a private local key; uncheck the option for session-only storage. Existing sessions remain usable and require the password once to opt into renewal. S3 keys are never saved.
- Forget the saved password without disconnecting or interrupting open transfers. Concurrent downloads share a bounded renewal; invalid credentials stop automatic login attempts until corrected. Sessions and saved credentials survive restarts and updates and are shared by this installation's administrators.
- Show clear restricted-file warnings, a connection progress indicator and translated account controls in all 27 languages. Login errors never expose authentication responses or trigger a DSM sign-out.
- Keep resume and checksum verification for authenticated transfers. Refuse external/insecure redirects and HTML login pages returned in place of non-HTML downloads.

## File selection

- Keep the file selection list scrollable inside small DSM windows, with a visible draggable scrollbar and a fixed Done button.
- Use a new DSM package revision to refresh cached frontend assets.

## Validation

The Python suite includes account persistence, encrypted credentials, shared automatic renewal, incorrect passwords, expiry, logout, credential scoping, safe failures, stale metadata prevention, updating an existing task and resuming a checksum-verified transfer with saved credentials. Browser tests cover the default remember option, opting out, forgetting a password without logging out, the account dialog, disabled controls during login, errors, password clearing, restricted-file warnings and compact windows.

Authentication and restricted-download tests use simulated Internet Archive responses. Access to a particular restricted item must be confirmed with the user's own authorized account. No real account credentials are included in tests, screenshots or release artifacts.

Install the SPK over the existing installation through Package Center. Settings, tasks and downloaded files are retained; no uninstall is needed.
